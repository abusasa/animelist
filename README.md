# abusamat's archive (v2)

Личный минималистичный медиа-архив в стиле Hyprland Tiling:
- **АНИМЭ** (`#E07A9A`), **ФИЛЬМА** (`#9B7EDE`), **СЕРИАЛКА** (`#D9535F`), **ЧИТАЛКА** (`#00875F`), **ГИТАРКА** (`#E7E5DF`) + создание новых категорий в админке.
- Свёрнутые вкладки снизу (`СТАТИСТИКА`, `СВЕДЕНИЯ`, `ЛОГИ`) с плавным выездом тайлов и перетаскиваемым изменением размера на ПК, и всплывающими карточками на телефоне.
- Вход по паролю с прямым редактированием прямо на странице (`−`/`+` серий/сезонов/страниц, смена и загрузка постеров, редактирование заметок) и синхронизацией в GitHub через API.
- Первая версия сайта сохранена в ветке и теге `v1-archive`, в папке `archive-v1/` и доступна по `/v1/index.html`.

## Запуск локально

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Деплой на Vercel

Подключи репозиторий `abusasa/animelist` в Vercel и добавь переменные окружения:
- `ADMIN_PASSWORD` — твой пароль для входа в режим редактирования
- `GITHUB_TOKEN` — Fine-grained PAT с правом `Contents: Read & Write` для `abusasa/animelist`
- `GITHUB_REPO` — `abusasa/animelist`
- `GITHUB_BRANCH` — `main`
